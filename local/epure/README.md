# Outils Épure (local_epure)

Plugin compagnon du thème [Épure](../../theme/epure). Il est facultatif : le thème fonctionne seul.

Il apportera :

- le **vocabulaire** appliqué à tout Moodle (cours, inscrits, enseignants), grâce aux paquets de langue locaux de Moodle ;
- avec **IOMAD** : le tableau de bord des entreprises, et la couleur, le logo et le vocabulaire propres à chaque entreprise (entreprise, département).

État actuel (version 0.1) : squelette du plugin et détection d'IOMAD, visible dans Administration du site › Plugins › Plugins locaux › Outils Épure.

## Installation

Copiez le dossier `epure` dans le dossier `local` de votre Moodle (`public/local` à partir de Moodle 5.1), puis lancez la mise à jour.
