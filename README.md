# Épure

Thème Moodle moderne, sobre et accessible, compatible **Moodle 4.5 LTS et 5.x**, avec un plugin compagnon pour **IOMAD**.

![Aperçu du thème](theme/epure/pix/screenshot.png)

## Contenu du dépôt

| Dossier | Composant | Rôle |
|---|---|---|
| [`theme/epure`](theme/epure) | `theme_epure` | Le thème |
| [`local/epure`](local/epure) | `local_epure` | Plugin compagnon facultatif : vocabulaire, fonctions IOMAD |

Les dossiers reprennent l'arborescence de Moodle : copiez `theme/epure` et `local/epure` aux mêmes endroits dans votre Moodle.

La feuille de route et les décisions de conception sont dans [ROADMAP.md](ROADMAP.md).

## Compatibilité

Moodle 4.5 LTS, 5.0 et 5.1, PHP 8.1 à 8.3, avec ou sans IOMAD. Chaque modification est vérifiée par l'intégration continue sur ces versions.
